# clone-tabnews-ai
Implementation of https://tabnews.com.br for https://curso.dev using AI agents

Página em Next.js 16.2.12 com App Router e JavaScript.

Requer Node.js 20.9 ou superior e [pnpm 10.34.9](https://pnpm.io/10.x/installation).

```bash
pnpm install
pnpm dev
```

Abra http://localhost:8000. No Codespaces, use o link da porta 8000.

Para produção, execute `pnpm build` e depois `pnpm start`.
