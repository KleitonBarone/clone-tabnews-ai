# Contexto do projeto

## Proposta

O projeto se chama `clone-tabnews-ai`. Sua proposta é implementar um clone do TabNews (<https://tabnews.com.br>), seguindo o <https://curso.dev> e usando agentes de IA.

## Tecnologias

- Next.js com App Router.
- React.
- JavaScript.
- Node.js.
